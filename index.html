Matriculator: Sistema de Reconocimiento de Matrículas

Desarrollo técnico y análisis de lenguajes para Inteligencia Artificial

1. Introducción y Caso de Uso (Paso 1)

Matriculator es una aplicación hipotética diseñada para automatizar el acceso a aparcamientos mediante la detección y lectura de matrículas en imágenes de cámaras de seguridad[cite: 1]. Su objetivo es agilizar el flujo de vehículos y reducir el error humano, manteniendo estrictas políticas de privacidad sin almacenar datos personales innecesarios[cite: 1].

2. Comparativa de Lenguajes y Google Trends (Paso 2)

Análisis de Interés Global (Google Trends)

A partir de los datos exportados en formato CSV (alojados en la carpeta data/ del repositorio)[cite: 1], se ha evaluado el interés de búsqueda global y en YouTube de los lenguajes evaluados (*Python, JavaScript, R, C++, PHP y Java*)[cite: 1]. Estudio de Características

Para un entorno de visión artificial y OCR, Python destaca por su enorme ecosistema de librerías especializadas (OpenCV, EasyOCR). Por su parte, JavaScript ofrece un gran rendimiento web, mientras que C++ aporta velocidad pero con una complejidad de desarrollo muy elevada para prototipos de IA.

Decisiones Finales Justificadas

  • Lenguaje principal para la aplicación: Python[cite: 1]. Permite gestionar tanto la lógica de la interfaz web (mediante frameworks ligeros) como el backend de manera unificada.
  • Lenguaje principal para la IA: Python[cite: 1]. Es el estándar indiscutible gracias a la disponibilidad inmediata de modelos preentrenados de visión artificial.
  • Descarte de alternativas: Se descarta C++ por su excesiva complejidad en el desarrollo de capas de aplicación, y Java, PHP o R por la falta de un ecosistema maduro y nativo orientado a la implementación rápida de modelos de reconocimiento de caracteres[cite: 1].
