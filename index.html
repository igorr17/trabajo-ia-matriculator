2. Comparativa de Lenguajes y Decisiones (Paso 2)

Análisis de Interés Global (Google Trends)

A partir de los ficheros CSV alojados en data/, se observa que Python lidera de forma aplastante el interés global en búsquedas web y YouTube para Inteligencia Artificial, mientras que lenguajes como JavaScript o Java se mantienen en entornos web y de sistemas tradicionales.

Características Fundamentales de los Lenguajes

  • Facilidad de aprendizaje y legibilidad: Python destaca por su sintaxis limpia y sencilla, ideal para desarrollos rápidos[cite: 1]. C++ y Java tienen una curva mucho más pronunciada.
  • Análisis estadístico: R es el referente indiscutible para estadística avanzada[cite: 1], aunque limitado para producción general de IA.
  • Mantenimiento e integración: JavaScript y Python ofrecen una excelente compatibilidad con APIs, web y bases de datos[cite: 1]. PHP queda relegado a entornos web clásicos.

Cierre y Decisiones Tomadas

  • ¿Son distintos el lenguaje de la aplicación y el de la IA? No, en este caso utilizaremos Python para ambos. Esto simplifica drásticamente la arquitectura al no tener que comunicar dos backends diferentes.
  • Lenguaje principal elegido: Python[cite: 1], tanto para la lógica general de la aplicación web como para el motor de reconocimiento óptico y visión artificial.
  • ¿Por qué se descartan los demás?
    • C++: Se descarta por su alta complejidad y tiempo de desarrollo excesivo para los objetivos del proyecto.
    • R: Se descarta porque, aunque excelente en estadística[cite: 1], carece de la versatilidad de Python para integrar modelos de visión artificial en una aplicación web en producción.
    • Java y PHP: Se descartan por la ausencia de un ecosistema nativo y maduro para modelos de IA y OCR.
    • JavaScript: Aunque válido para web, se queda atrás frente a Python en la disponibilidad de modelos preentrenados de reconocimiento de matrículas.
