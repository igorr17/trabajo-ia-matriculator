🚗 Matriculator

Sistema de Reconocimiento de Matrículas | Propuesta Técnica de Inteligencia Artificial

1. Introducción y Caso de Uso (Paso 1)

Matriculator es una aplicación orientada a automatizar el acceso a aparcamientos mediante la detección de matrículas en imágenes de cámaras de seguridad. Su diseño prioriza la agilidad en el flujo vehicular y el cumplimiento estricto de la privacidad.

2. Comparativa de Lenguajes y Decisiones (Paso 2)

📊 Análisis de Interés Global (Google Trends)

A partir de los ficheros exportados y alojados en la carpeta data/, se constata que Python encabeza de forma absoluta el interés mundial en búsquedas web y YouTube destinadas a la Inteligencia Artificial.

⚙️ Características Fundamentales

  • Facilidad de aprendizaje y legibilidad: Python sobresale por su sintaxis intuitiva y limpia, facilitando un desarrollo rápido y mantenible.
  • Análisis estadístico: R se posiciona como el estándar absoluto para el cálculo estadístico avanzado, aunque con menor versatilidad para despliegues de IA en producción.
  • Integración web y mantenimiento: Python y JavaScript ofrecen una compatibilidad excelente con APIs, bases de datos y entornos web.

🎯 Cierre y Decisiones Tomadas

  • ¿Son distintos el lenguaje de la aplicación y el de la IA? No, en este diseño emplearemos Python para ambas capas, unificando el código y evitando la complejidad de comunicar backends heterogéneos.
  • Lenguaje principal elegido: Python para la gestión global y la capa de visión artificial / OCR.
  • ¿Por qué se descartan los demás?
    • C++: Descartado por su elevada complejidad y el tiempo excesivo de desarrollo que implicaría.
    • R: Descartado porque carece de la versatilidad de Python para integrar modelos de visión en una aplicación web en producción.
    • Java y PHP: Descartados por la falta de un ecosistema nativo sólido en librerías de IA y reconocimiento de matrículas.
    • JavaScript: Queda rezagado frente a Python en la disponibilidad de modelos de Deep Learning preentrenados.

4. Lenguajes de marcado y formatos de datos

HTML

HTML es un lenguaje de marcado que se usa para crear y organizar el contenido de una página web, este usa elementos como títulos, textos, imágenes, botones, listas, etc.

En Matriculator se usaria para crear la interfaz de la aplicación, en donde el usuario interactuaria con el sistema.

XML

XML es un formato de texto que te ayuda a organizar y almacenar datos de una forma estructurada, este usa etiquetas y puede compartir la información con diferentes sistemas.

En Matriculator podría usarse para intercambiar información estructurada con otros sistemas de la empresa.

JSON

JSON es un formato de texto que se usa para representar e intercambiar datos, ya que su estructura usa claves y valores y es muy usado en aplicaciones web y APIs.

En Matriculator podría usarse para enviar datos de una imagen y recibir información acerca de la matrícula detectada.

Markdown

Markdown es un lenguaje de marcado un poco simple que puede dar formato al texto, osea que puede crear títulos, listas, tablas y enlaces.

En este proyecto se utilizaría para crear el archivo README.md de GitHub, ahí es donde se documenta el trabajo.

CSV

CSV es un formato de texto que nos ayuda a almacenar muchos datos en filas y columnas, no es tan complejo y puede ser leído por diferentes programas.

En Matriculator se utilizaría para guardar los datos que se han obtenido de Google Trends y utilizarlos depsues para crear el gráfico de la web.
