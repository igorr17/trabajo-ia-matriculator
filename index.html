🚗 Matriculator

Sistema de Reconocimiento de Matrículas | Propuesta Técnica de Inteligencia Artificial

1. Introducción y Caso de Uso (Paso 1)

Matriculator es una aplicación orientada a automatizar el acceso a aparcamientos mediante la detección de matrículas en imágenes de cámaras de seguridad[cite: 1]. Su diseño prioriza la agilidad en el flujo vehicular y el cumplimiento estricto de la privacidad[cite: 1].

2. Comparativa de Lenguajes y Decisiones (Paso 2)

📊 Análisis de Interés Global (Google Trends)

A partir de los ficheros exportados y alojados en la carpeta data/[cite: 1], se constata que Python encabeza de forma absoluta el interés mundial en búsquedas web y YouTube destinadas a la Inteligencia Artificial, superando ampliamente a los lenguajes tradicionales de sistemas o web.

Visualización dinámica: El gráfico interactivo generado directamente a partir de trends.csv se integra en este apartado de la web estática[cite: 1].

⚙️ Características Fundamentales

  • Facilidad de aprendizaje y legibilidad: Python sobresale por su sintaxis intuitiva y limpia, facilitando un desarrollo rápido y mantenible[cite: 1]. Lenguajes como C++ o Java requieren una curva de aprendizaje mucho más pronunciada.
  • Análisis estadístico: R se posiciona como el estándar absoluto para el cálculo estadístico avanzado[cite: 1], aunque con menor versatilidad para despliegues de IA en producción general.
  • Integración web y mantenimiento: Python y JavaScript ofrecen una compatibilidad excelente con APIs, bases de datos y entornos web[cite: 1].

🎯 Cierre y Decisiones Tomadas

  • ¿Son distintos el lenguaje de la aplicación y el de la IA? No, en este diseño emplearemos Python para ambas capas, unificando el código y evitando la complejidad de comunicar backends heterogéneos.
  • Lenguaje principal elegido: Python[cite: 1] para la gestión global y la capa de visión artificial / OCR.
  • ¿Por qué se descartan los demás?
    • C++: Descartado por su elevada complejidad y el tiempo excesivo de desarrollo que implicaría para este proyecto.
    • R: Descartado porque, a pesar de su gran potencial estadístico[cite: 1], carece de la versatilidad de Python para integrar modelos de visión en una aplicación web en producción.
    • Java y PHP: Descartados por la falta de un ecosistema nativo sólido y maduro en librerías de IA y reconocimiento de matrículas.
    • JavaScript: Aunque excelente para la web, queda rezagado frente a Python en la disponibilidad de modelos de Deep Learning preentrenados.
